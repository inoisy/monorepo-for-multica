# agents-init

Скилл для агентов (Claude Code и совместимые): собирает `AGENTS.md` для
проекта и проверяет уже существующий.

Нужен там, где агент каждый раз заново выясняет, чем гонять тесты, от какой
ветки отводиться и куда целить MR, — и каждый раз ошибается по-своему.

## Что делает

**Сборка.** Разведывает репозиторий: команды и пакетный менеджер, раннер
тестов с реальным прогоном и замером, состояние типов и линта, что делает CI
на самом деле, хуки на коммит, базовая ветка и формат коммитов, наличие
`glab`, трекер, уже написанные инструкции, конкурирующие способы делать одно
и то же. Конвенции Лоции — язык, имена веток, формат коммита, ссылка на задачу
в Сфере, запрет следов инструмента — подставляются заготовками, которые
достаточно подтвердить. Вопросы задаются одной пачкой и только о том, чего в
коде не видно.

На выходе: минимальный `AGENTS.md` и подключение для используемых агентов.
Для Claude Code — `CLAUDE.md` с импортом `@AGENTS.md`, в том числе рядом
с вложенными файлами подпроектов. Существующие инструкции сохраняются;
правила в `.claude/rules/` создаются по необходимости с ограничением по путям.
Команды проверяются по [VERIFY.md](./VERIFY.md): аудит сам по себе не запускает
push, deploy или миграции, а недоступные проверки отмечаются в отчёте.

**Проверка.** Отвечает на четыре вопроса по существующему файлу: грузится ли
он вообще, не врут ли его команды и числа, не противоречит ли он сам себе, не
раздут ли настолько, что правила из него теряются. Находки выдаются по
убыванию вреда. Режим `audit` оставляет инструкции без изменений; `update`
исправляет подтверждённые проблемы, сохраняя спорные правила до решения
владельца. Повторный запуск не создаёт дубли импортов и правил.

## Владение файлом

Это раздел для человека, а не для агента: правила, которые нельзя проверить
по файлу, потому что они про процесс вокруг него.

В [исследовании ETH Zurich, версия 2](https://arxiv.org/abs/2602.11988v2)
контекстные файлы в среднем увеличивали стоимость вывода более чем на 20%
и в целом не улучшали долю решённых задач. Это результат исследованных
конфигураций, а не универсальная цена любого файла.

- **Польза проверяется на задачах проекта.** Исследование не проверяет этот
  скилл: ответы человека не гарантируют полезность полученного файла.
  Сравнивать выполнение одинаковых задач с прежними и новыми инструкциями:
  соблюдение правил, результат, лишние действия и стоимость. Сценарии
  проверки самого скилла — [SCENARIOS.md](./SCENARIOS.md).
- **Файл чистится вычитанием, а не только дополняется.** По корпусу из 2303
  файлов (arXiv:2511.12884) они правятся как конфиг — часто и мелко, почти
  всегда добавлением; разовая большая чистка даёт передышку, после которой
  рост возобновляется, если вычитание не вошло в привычку.
- **Причину удаления держит записанная причина.** По данным о росте таких
  файлов (arXiv:2608.11095) вероятность удаления инструкции падает с её
  возрастом: забыв, зачем правило вносили, его боятся трогать, и оно остаётся
  навсегда.

## Исследования

Чек-лист опирается на спецификацию и документацию вендора, а также на четыре
работы:

- https://agents.md/ — спецификация формата;
- https://code.claude.com/docs/en/memory и
  https://code.claude.com/docs/en/best-practices — механика загрузки и
  рекомендации вендора;
- [arXiv:2602.11988v2](https://arxiv.org/abs/2602.11988v2) — эффективность
  и стоимость контекстных файлов в исследованных конфигурациях;
- arXiv:2511.12884 — корпус из 2303 файлов: как они устроены и как правятся;
- arXiv:2608.11095 — почему такие файлы растут и не худеют.

Доказательства по эффективности **противоречивы**: есть работа с обратным
знаком (arXiv:2601.20404 — на реальных pull request'ах с `AGENTS.md` агент
завершал быстрее и с меньшим расходом токенов). Пункты чек-листа, где
источники расходятся, помечены в нём явно.

## Установка

Скопировать или слинковать каталог в личные скиллы — работает во всех
проектах на машине:

```bash
ln -s "$PWD/skills/agents-init" ~/.claude/skills/agents-init
```

Либо положить в сам проект, чтобы скилл достался всей команде через
репозиторий:

```bash
cp -r skills/agents-init <проект>/.claude/skills/agents-init
```

## Запуск

```
/agents-init
```

Без аргументов: если инструкций нет — собирает, если есть — проверяет.
Учитываются также `CLAUDE.md` и правила других агентов.

```text
/agents-init create — собрать инструкции, сохранив существующие правила
/agents-init audit — проверить без изменения инструкций
/agents-init update — проверить и исправить подтверждённые проблемы
```

Можно указать подпроект: «обнови инструкции только для mcp/web-reader».
Конвенции Лоции подключаются при подтверждённой принадлежности проекта;
для других команд сохраняются их соглашения.

## Состав

- `SKILL.md` — сборка: разведка, заготовки конвенций, вопросы, сборка, сдача.
- `AUDIT.md` — проверка существующего файла, отдельной последовательностью.
- `CHECKLIST.md` — критерии годности файла; применяется агентом целиком, на
  сдаче сборки и в аудите.
- `AGENTS.template.md` — каркас файла с подстановками.
- `VERIFY.md` — границы проверки команд и статусы доказательств.
- `SCENARIOS.md` — сценарии регрессии при изменении самого скилла.
- `LOCIA.md` — профиль соглашений для проектов Лоции.
