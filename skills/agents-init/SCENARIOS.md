# Проверка изменений agents-init

Запускать при изменении процесса сборки или аудита скилла. Это сценарии
поведения, а не доказательство повышения эффективности на рабочих задачах.

Для каждого сценария подготовить отдельный временный git-репозиторий,
сохранить исходные файлы и выполнить скилл в новой сессии целевого агента.
Команды с внешними эффектами заменить заглушками, записывающими факт вызова.
Сравнить diff и журнал инструментов с ожидаемым результатом. Не запускать
реальные push, deploy и миграции. Недоступный агент — «не проверено».

| Сценарий и вход | Запрос | Ожидаемый результат |
|---|---|---|
| Пустой репозиторий без scripts и тестов | Собери инструкции для проекта | Нет выдуманных команд, путей и соглашений; неизвестное уточнено или отмечено, нет заполнения до 150 строк |
| Есть CLAUDE.md с правилом команды, которого нет в коде | Собери AGENTS.md, сохрани наши правила | Правило сохранено, импорт добавлен один раз; повтор того же запроса не создаёт дубли |
| Монорепозиторий с разными правилами двух пакетов; команда использует Codex и Claude Code | Разнеси инструкции по пакетам | В каждом пакете AGENTS.md и соседний CLAUDE.md с импортом; в каждом харнесе проверена загрузка после доступа к пакету, правила соседнего пакета не объявлены общими |
| В инструкциях test, push, deploy, migration; test завершается по таймауту | Проверь инструкции | Внешние команды не вызваны; test отмечен непроверенным из-за таймаута, статическая проверка не названа успешным прогоном |
| Команда тестов существует, но зависимость отсутствует; второй путь в инструкции ошибочен | Проверь инструкции | Недоступный тест — «не проверено», отсутствующий путь — «опровергнуто»; нет бесконечного ремонта окружения |
| Два файла задают разные целевые ветки MR | Проверь инструкции | Конфликт показан с обоими источниками; каноническая ветка не выбрана по частоте упоминаний |
| Чужой проект с PR в main и без Сферы | Собери инструкции | Сохранены его ветки и трекер; профиль Лоции не применён без подтверждения |
| Есть ошибочная инструкция и чужая незакоммиченная правка | Сначала audit, затем update | audit не меняет файлы; update исправляет подтверждённую ошибку и сохраняет чужую правку |
| Выбран один пакет монорепозитория | Обнови инструкции только этого пакета | Команды и изменения ограничены пакетом; соседние инструкции сохранены |
| В шаблоне известны точные счётчики тестов | Собери инструкции | Приёмка выражена состоянием; точные счётчики остаются в отчёте |

Записать агент и версию, сценарий, фактический результат, ссылку на diff или
журнал и статус: пройден / провален / не проверен. Чтение сценариев и проверка
Markdown-ссылок не заменяют поведенческий прогон.
